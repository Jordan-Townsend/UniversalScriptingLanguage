# Versioned guarded integer function profiles

`usl.family.guarded-int32.function-fragment.v1` covers Kotlin, Scala, D, Groovy, Haskell, OCaml, Clojure, Common Lisp, Scheme, Racket, Elixir, Erlang, Fortran, Ada, Perl and Delphi. Each host's actual version, observed executable/managed-library identity and native build flags are recorded. Delphi is explicitly Free Pascal Delphi mode; Scheme is the installed Guile profile, Common Lisp the installed SBCL profile, and the other profiles use their recorded upstream implementations. Exact source/parser/tool identity is required; complete normative specification/library coverage remains unqualified.

Admitted source contains one canonical function fragment with one to eight bound integer parameters and a pure integer expression or complete guarded branch. Primitive operations are canonical signed decimal literals, variables, unary signs, addition, subtraction, multiplication and language-correct integer comparisons. Integer inputs, every reachable intermediate and outputs must remain in the explicit int32 contract domain. No floats, modules/libraries, closures, objects, recursion, arbitrary source compilation units, effects, casts or implicit truthiness are inferred. Uncertain/unsupported constructs are rejected.

The actual upstream AST establishes structure. Haskell's operator-token CST is resolved using only admitted Prelude fixities; user operator/fixity declarations are rejected. Native equality spelling is handled per language rather than by replacing arbitrary tokens. Groovy's native AstBuilder establishes actual typed method/return AST; the generic grammar is not substituted when it rejects valid Groovy syntax. Fortran/Delphi result statements must be the entire admitted function body, including complete else branches. Actual compiler or interpreter execution still supplies the native admission/acceptance gate.

Guarded Z3 proofs cover original AST expression, independently checked typed IR, the actual emitted target AST and equality back to the original expression. Native emitted guards use direct primitive comparisons, avoiding a trusted comparison-helper substitution. A dead branch cannot create spurious overflow, while overflow in a condition or any reachable intermediate is rejected. Postconditions are explicit user/test contracts; arbitrary natural-language intent and entire compiler/runtime correctness are not proved. Each proof uses an independent solver context.

The admitted source, AST, intent and invocation identity is frozen by digest. Mutation before emission, build or execution fails. Compiled hosts retain one exact ephemeral build for the two target checks, verify source/harness, observed tool/library and output artifact identities, then execute again. No native observation is replayed. Full native dependency closure remains an outstanding qualification gate. Runtime/artifact changes invalidate the relevant evidence.

Run the supplied `examples/family_functions/absolute.*` and corresponding intent JSON through `function-verify`, or execute `python -m tools.qualify_family_functions --workers 3`. The qualifier uses isolated, resource-admitted processes for sixteen languages and independently authored doubling, squared-distance, magnitude, dead-square and ordered-subtraction cases. Training/test labels are never generated from translated execution results. Failed cases, compiler errors and counterexamples remain visible.

The learned transfer path reads a promoted scalar `.usl` skill's actual AST and immutable journal identity, proves an independent original-domain contract, emits language syntax from those operators and bindings, reparses and proves the native expression, runs the original native source and generated Python/JavaScript separately, and freshly executes original `.usl` transfer cases. It cannot promote/retrain on failed transfer labels. Sealed discovery holdouts remain distinct from search inputs; privileged host access is not an encrypted enclave. This is finite grammar/task transfer, not universal autonomous language learning.
