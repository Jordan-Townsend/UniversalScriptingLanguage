# Calibrated temporal sensory grounding

`sensory_grounding.py` supplies a usable reference-calibration and alignment
mechanism. It fits an affine transducer model only from training references,
rejects non-affine/rank-deficient data, and validates disjoint protected holdout
references before installation. Model reload independently recomputes the
coefficients rather than trusting a self-hash. Raw uncertainty intervals must
remain inside the calibrated domain; there is no silent extrapolation.

Typed channels cover encoded image brightness or illuminance, PCM amplitude or
sound pressure, force, joint angle, acceleration/angular velocity, temperature,
and identified chemical concentrations. Chemical channels require an analyte;
body channels require a coordinate frame. Units are exact and per quantity.
Coordinate frames are checked, not automatically transformed. A chemical
concentration reading does not establish biological smell or taste.

Device clocks have separately fitted mappings to host seconds, protected
reference checks and explicit rate-drift limits. A bounded buffer rejects
duplicate/replayed sample identities and non-increasing timestamps. Frames
select the nearest qualified capture within the requested event window,
including the estimated timing uncertainty. Missing optional channels carry
zero vector placeholders, false availability masks, null uncertainty and an
explicit reason. Missing required channels, excessive uncertainty, low declared
confidence, stale frames and wholly missing frames are rejected.

Feature normalization is declared in the slot contract; it is not silently
learned. Physical quantities retain their original canonical units. Empirical
uncertainty radii combine declared raw uncertainty, observed reference residuals
and reference uncertainty. They are not a distribution-free guarantee beyond
the supplied calibration cases. Source confidence is not a calibrated class
probability. Sensor and clock drift-reference failures invalidate queued frames.
Recovery requires fresh training/holdout reference identities and source
evidence; reinstalling a cached model cannot clear a drift failure.

Revocable grants bind sensor identity, source identity, source mode and expiry.
The grant clock belongs to the trusted host, with rollback rejected. Grants are
checked when reading, when aligning, and immediately before and after guarded
pure actions or learned inference. Renewal never restores old-generation
observations. A cached frame cannot bypass permission revocation. The guarded
action API prohibits automatic replay and supports pure computations; it does
not implement physical actuation or undo external effects.

Image and WAV adapters decode bounded real file snapshots. Image values are
encoded grayscale means, not a claim of calibrated optical illuminance. WAV
values are exact decoded PCM RMS, not calibrated microphone sound pressure.
Snapshots are retained under a 16MB budget and copied privately for the existing
trained digit model. Changing the original file cannot replace the observation
used for inference. Predictions are rejected if a grant is revoked during
inference. Tactile, joint, IMU, thermal and chemical model weights are not
invented; those channels remain typed calibrated inputs for downstream tasks.

The main APIs are:

- `fit_calibration(request)` returns a reference-qualified model or rejects it.
- `RevocableSensorGrants.grant(..., approved=True)` and `revoke(sensor_id)` manage
  explicit source permissions; the default clock is the real host clock.
- `TemporalSensoryGrounding.install_calibration(model)` installs a checked model.
- `observe(sample)` accepts a typed raw reading; `observe_file(...)` decodes an
  authorized image or PCM WAV snapshot.
- `frame(slots, event_time=..., max_skew=..., max_age=...)` emits calibrated
  aligned features and missingness.
- `event(frame, conditions)` evaluates a typed threshold conjunction with
  `true`, `false` or `unknown` results, respecting uncertainty intervals.
- `action_feature(frame, slot_id, approved=True)` returns a typed physical value;
  `action_packets(...)` adapts it to existing entity packets. Legacy packet units
  are grouping conventions; `evidence.canonical_units` retains real per-feature
  units. The owner must revalidate the originating session before dispatch.
- `guarded_action(frame, callback, approved=True)` executes one pure computation
  under before/after permission checks.
- `perceive(frame, bundle, approved=True)` invokes the existing bounded trained
  image/audio model on immutable private snapshots. `infer_callback` supports
  the owner's existing guarded neural worker when the main process lacks Torch.

Run the standard qualification with:

```sh
python -m tools.qualify_sensory_grounding --output test_results/v4.7.0_sensory
```

With the optional neural runtime, also exercise the trained model bridge:

```sh
"$USL_NEURAL_PYTHON" -m tools.qualify_sensory_grounding \
  --output test_results/v4.7.0_sensory \
  --bundle test_results/v4.5.0_multimodal
```

The independently specified fixtures include an actual 8x8 PGM with every pixel
128, an actual 16-bit PCM waveform with amplitude ±8192, and declared reference
standards for the other six channels. Known outputs are 128/255, 0.25, 5N, 0rad,
1m/s², 35°C, 550ppm CO₂ and 0.2mol/L NaCl. These reference values exist before
fitting. The declared contact conjunction checks aligned force, acceleration
and audio thresholds. The included `.usl` action consumes calibrated force and
prints integer `11`, verified against a separately retained intent. The optional
model bridge reads the existing real handwritten digit and synthesized speech
fixtures and checks its prediction against their retained label, 9.

All hardware/reference simulations remain explicitly `synthetic_test`. The
recorded handwriting and synthesized speech remain distinct source modes.
No camera or microphone device was found during qualification; no physical
sensor modality is claimed qualified, and no human sensory equivalence is
claimed. Physical deployment still needs identified devices, independent
measurement standards, actual clock/reference captures, geometric transforms,
driver provenance and acceptance fixtures under the owner's permissions.
