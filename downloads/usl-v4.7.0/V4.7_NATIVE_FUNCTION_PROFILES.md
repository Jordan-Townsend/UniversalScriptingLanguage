# Real native integer function profiles

C, C++, Go, Rust, Java and C# import one actual upstream-parsed function fragment into the typed/effect IR and emit executable Python or JavaScript. The source AST, independently checked actual IR, and actual emitted-function AST must satisfy an explicit integer intent contract. Z3 checks every modelled intermediate for signed int32 overflow. Compiler execution and independent invocation cases run freshly; caches never supply execution observations.

These six profiles accept 1–8 explicitly typed signed-integer parameters and one pure return composed of canonical decimal literals, variables, unary signs, addition, subtraction and multiplication. Input bounds and an independently supplied postcondition are required. C/C++ native wrappers assert a four-byte int ABI. Go executes real Go int operations restricted to the proved int32 domain; Rust uses i32 and overflow checks; Java and C# use native int static methods. Calls, extra declarations, side effects, modules, object systems, division, casts, recursion, floats, arbitrary compilation units and full libraries remain unsupported. Actual compiler failures fail qualification rather than silently selecting another host.

A function fragment is a narrower profile than the six closed-source profiles (Python, JavaScript, Ruby, TypeScript, PHP and Lua). Neither kind certifies an entire language standard. Full normative libraries, effects, ABI, review and cross-platform gates remain separate.

Run from the source root after activating the installed tools:

```sh
python -m usl_systems function-verify examples/native_scalar/twice.c --language c --target javascript --function twice --contract examples/native_scalar/intent.json --invocations examples/native_scalar/invocations.json --i-allow-execution --output /tmp/native-proof.json
python -m tools.qualify_native_scalar_frontends
```

Use the corresponding supplied `.cpp`, `.go`, `.rs`, `.java` or `.cs` fragment and its language ID. The qualifier covers a doubling function and a squared-distance polynomial, both targets, six independently authored invocation cases per comparison, and rejected wrong intents, overflow domains, outside-domain inputs and foreign declarations. Counterexamples remain evidence; unsupported semantics remain obligations.
