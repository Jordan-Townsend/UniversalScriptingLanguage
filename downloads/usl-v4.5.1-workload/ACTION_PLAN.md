This package preserves the hash-verified v4.5 base. Run the separate addon against
that source so its original regression and release evidence remains intact.

```bash
source /workspace/.onboarding/activate-usl.sh
python run.py --source-root /workspace/usl-v4.1.0 --output results --i-allow-execution
python -m unittest test_workload
```

Elsewhere, install the v4.5 dependencies and supply its extracted source directory
with `--source-root`. Linux/POSIX is the qualified execution host. The addon uses
real installed Python/Node and compiler tools; it does not ship native binaries.

`results/results.json` contains every calibration sample, native observed output,
independent expected result, source/runtime/dependency identity, heldout decision,
cost/fairness data, success-collapse attempts, numeric worker accounting,
compression/CAS result and equation applicability record. The reported speedup
applies only to these inputs and this machine, not all languages or future tasks.
